## In GitHub Codespaces starten

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/drulrichwinkler/2026-syspro-ebnf)

Oder lokal in VS Code mit der Erweiterung **Dev Containers**:
_Command Palette → "Dev Containers: Reopen in Container"_.

Beim ersten Start werden Python 3.12 und [`uv`](https://github.com/astral-sh/uv)
installiert und das Projekt in `lösung/` automatisch synchronisiert.

## Schnellstart

```bash
cd lösung
uv run pytest                  # Tests
uv run python calculator.py    # interaktiver Tischrechner
```
